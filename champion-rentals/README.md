# Champion Rentals Website

Static website for Champion Rentals: construction and landscaping equipment rentals.

- `index.html`: the page
- `styles.css`: styling (navy and orange from the logo)
- `inventory.js`: equipment catalog, grouped by category. Edit this to add or remove items.
- `app.js`: equipment search and filters, plus the "open now" indicator (Mon–Fri 8am–4pm Eastern)
- `assets/logo.jpg`: the company logo

To view it, open `index.html` in a browser. To host it, upload this folder to any static host,
such as GitHub Pages, Netlify or your web host.
